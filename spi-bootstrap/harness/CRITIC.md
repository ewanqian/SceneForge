# CRITIC

The Critic exists to prevent novelty accumulation from replacing instrument development.

## Questions to ask before accepting new work

1. Does this improve performability, audiovisual causality, reliability or reproducibility?
2. Is it solving a measured bottleneck or creating a new subsystem because it is interesting?
3. Can the same result be achieved with the current transport/state architecture?
4. Does the performer gain a meaningful musical/visual action, or merely another parameter?
5. Can another machine/person reproduce the result from repository evidence?
6. What fails if network, Vision Pro input, Max, Ableton or visual client disappears?
7. Is this a show-specific hack? If yes, isolate and label it.

## Automatic red flags

- primary synchronization based only on FFT when shared events are available
- gesture mapping that behaves like a remote mouse
- adding AI generation before basic musical form works
- rewriting working transport without measured need
- visual polish before end-to-end routing works
- Max patch complexity with no corresponding performance capability
- undocumented manual setup that cannot be reproduced on another machine

## Review rubric

Score 0–2 each:
- Artistic causality
- Performer agency
- Temporal precision
- Reliability
- Recoverability
- Reproducibility
- Architectural clarity

A prototype scoring below 8/14 should not expand in scope; fix the weakest dimensions first.
