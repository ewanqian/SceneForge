# ROADMAP — to 2026-12-03

This roadmap is delivery-gated. Dates are not aspirational; if a gate misses, scope is reduced so rehearsal time is protected.

## Gate 0 — Transport proof
Deadline: 2026-10-30

Exit criteria:
- browser/Vision Pro input reaches Mac
- >=30 Hz continuous stream where device/browser permits
- discrete event integrity checked
- 10-minute run recorded
- reconnect behavior documented
- fallback input path defined

If missed:
- Vision Pro becomes optional for the next integration step
- desktop/browser input substitutes for it
- no dependent feature expansion until shared sound+image proof exists

## Gate 1 — Shared event proof
Deadline: 2026-11-05

Exit criteria:
- canonical performance-state schema in use
- one event controls both sound and visual
- Ableton remains timing/audio authority
- visual response is driven by shared event identity, not primary FFT/onset analysis
- 20–30 sec captured proof exists

## Gate 2 — SPATIAL SCORE 01 skeleton
Deadline: 2026-11-12

Build a 60–180 sec audiovisual study with:
- 4 sound voices: LOW / WOOD-BODY / METAL-TRANSIENT / TEXTURE
- 4 visual behaviors: IMPACT / CUT / SCATTER / FLOW
- one coherent rhythmic/event language
- basic performer control without laptop mousing during the core phrase

Exit criteria:
- full study can be played start-to-finish
- timing and audiovisual causality are legible
- Critic score >= 8/14 before scope expansion

## Gate 3 — Performance controls + recovery
Deadline: 2026-11-19

Add only the controls proven necessary for performance:
- ENERGY / DENSITY / SPACE / TENSION
- pedal pattern / fill / break / safe
- quantized discrete state changes

Exit criteria:
- performer can improvise core flow without touching laptop
- network/input failure enters a known safe behavior
- one integrated 10-minute run passes

## Gate 4 — Show feature freeze
Deadline: 2026-11-26

Freeze:
- software versions
- performance-state schema
- Ableton set
- Max/RNBO patch if used
- visual build
- pedal mappings
- network topology

After this date:
- no new show-critical feature unless it replaces an existing feature and passes PM + Validator review
- only reliability fixes, rehearsal findings and critical artistic corrections

## Gate 5 — Full rehearsal + backup
Deadline: 2026-11-30

Required:
- full rehearsal video
- final architecture diagram
- cue/state sheet
- startup sequence from cold boot
- backup mode and safe scene
- recovery from at least one simulated failure

## Performance
Date: 2026-12-03

Goal:
Perform a reliable spatial audiovisual instrument, not a collection of disconnected technical demonstrations.

## Post-show

Convert show-specific findings into reusable instrument modules. Do not let performance hacks silently become permanent architecture.
