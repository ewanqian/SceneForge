# Standard Exercise｜30 秒 Opening
## 场景铸造的第一条标准答案

**版本：** 0.1 · 2026-11-02  
**对应：** Minimal Input Lab · 02 Scene Forge / 场景铸造  
**用途：** 初学者先完整跟做一次，再进入自由创作

> 这一关不要求风格，不要求原创世界观，不要求高级软件。目标只有一个：第一次把“空间 + 时间 + 声音 + 光 + 屏幕 / 对象”的关系完整跑通。

---

## 1. 最终结果

完成一个约 30 秒的 Opening：

```text
00–06s   OPEN
06–12s   REVEAL
12–18s   BUILD 01
18–24s   BUILD 02
24–30s   PEAK
30s+     RELEASE
```

至少同时考虑：

- Music / Sound
- Performer 或 Object / Installation
- Light
- Screen / Visual

---

## 2. 为什么先做 Opening

Opening 很适合作为第一道练习，因为它天然要求你回答：

- 第一秒观众看到什么？
- 第一件出现的东西是什么？
- 什么应该晚一点出现？
- 怎么让空间从“小”变“大”？
- Peak 之前怎样留下余量？
- Peak 之后怎么收回来？

它比“做一个漂亮效果”更接近真正的演出编排。

---

## 3. 默认场景

只需要：

- 一个黑色空间；
- 一个中央主屏或主体；
- 一个可选的顶部 / 第二屏；
- 一个 Performer / Object placeholder；
- 一条主光；
- 一个观众视角。

不要先加复杂材质、反射、烟雾、粒子和十几个屏幕。

---

## 4. Cue Sheet

| Time | Function | Music / Sound | Performer / Object | Light | Screen / Visual |
|---|---|---|---|---|---|
| 00–06 | OPEN | 极弱 ambience | 静止 / 不出现 | 0–5% | 黑场 |
| 06–12 | REVEAL | 第一层 texture | 出现 / 唤醒 | 主光 10–20% | 中央内容 fade in |
| 12–18 | BUILD 01 | 加入 pulse | 保持 / 小幅动作 | 20–30% | 第二层内容进入 |
| 18–24 | BUILD 02 | rhythm 建立 | 移动 / 展开 | 40–60% | 多屏 / 空间关系展开 |
| 24–30 | PEAK | 一次明确 hit | 停 / 锁定 | 70–100% / flash | 第一次完整汇合 |
| 30+ | RELEASE | 减少材料 | 静止 | 回落 | 去掉至少一层 |

这不是唯一正确答案，而是第一条可以共同讨论的答案。

---

## 5. 跟做步骤

### A｜先搭 Gray Box

只放：floor / screen / camera / performer or object / light。

**通过条件：** 不看材质，也能理解比例和观看方向。

### B｜建立六个时间段

先不要填效果，只标：OPEN / REVEAL / BUILD / BUILD / PEAK / RELEASE。

**通过条件：** 30 秒不是一条平线。

### C｜先填 Music / Sound

即使没有原创音乐，也先用文字描述：

```text
ambience
→ texture
→ pulse
→ rhythm
→ hit
→ release
```

**通过条件：** 每段有明确的声音功能，而不是“放一首歌”。

### D｜填 Light

规则：不要一开始全亮。

**通过条件：** Peak 前仍有亮度余量。

### E｜填 Performer / Object

如果没有演员，用装置 / 几何体 / 书法主体 / 物件都可以。

**通过条件：** 主体至少有一次状态变化：出现、移动、停止、展开或消失。

### F｜最后填 Screen / Visual

现在才决定屏幕做什么。

**通过条件：** 屏幕不是唯一发生变化的媒介。

---

## 6. 第一次播放后只检查六件事

1. 第一秒是不是已经太满？
2. 第一个明确材料出现得够清楚吗？
3. 12–24 秒之间真的在推进吗？
4. Peak 是否比前面明显？
5. Performer / Object 是否和 Screen 有关系？
6. Release 是否真的拿掉了东西？

选最严重的一条。

---

## 7. V2 规则

第二版只允许改一个问题。

例如：

- 主体出现太早 → 延后 3 秒；
- Peak 不够明显 → 前面亮度全部降低；
- 所有媒介同时变化 → 错开 Light 与 Screen；
- 画面很满 → 删掉第二层内容；
- 没有空间感 → 让第二屏晚一点进入；
- 音乐没有结构 → 增加一个清晰 hit / break。

**不允许因为不满意就推翻整个工程。**

---

## 8. Remix / 自由改造

完成标准答案后，才进入自己的版本。

### 书法 / 文字

可以把主体改成笔画 / 字形：

```text
黑场
→ 第一笔出现
→ 笔势 / 墨迹增多
→ 空间扩大
→ 完整字形或结构出现
→ 留白 / 消散
```

### 实体装置

屏幕可以弱化甚至关闭，把 Object / Installation 作为主角。

### 音乐人

先用自己的曲式或 8 / 16 bar 结构替换时间段，再安排其他媒介。

### VJ / Visual Artist

保留 Screen 为主材料，但必须让 Light / Space / Silence 至少有一条独立作用。

## 9. 提交

必须提交：

- 场景 URL / 工程；
- 一张 Cue Sheet；
- 10–30 秒录屏；
- V1 / V2；
- 一句话：**我第二版只改了什么？为什么？**

---

## 10. 讲师使用规则

- 开场先完整播放标准答案，不解释；
- 学员第一次跟做时不开放高级扩展；
- 20–30 分钟后强制停下做 Checkpoint；
- 先完成，再解释 WHY；
- 只有通过 Standard Exercise 后才进入自由 Remix；
- Blender / TouchDesigner / Arena / WebGL 等进入扩展层，不吞掉主线。
