# 2026-10-31 舞台复刻｜课后回访：匿名反馈与后续路线

> 本文件是 Scene Forge / 场景铸造下 2026-10-31「舞台复刻」工作坊的课后归档。
> 只记录匿名、可复用的教学结论，不保存参与者姓名、账号、聊天截图或可识别私人信息。

## 1. 这轮回访确认了什么

工作坊的优势主要集中在三件事：

1. **视角打开得快**：参与者能够快速看到 AI、网页、预演、实时视觉如何进入同一条创作流程。
2. **案例具有吸引力**：真实演出、舞台视觉和工具演示能建立兴趣，并让初学者知道“原来还可以这样做”。
3. **工作流本身有价值**：AI 工具使用、寻找参考、快速迭代、版本保存与公开发表，被多位参与者视为可直接带走的方法。

但回访中反复出现的缺口也很集中：

- 案例看懂了，但还想知道**为什么这样搭、为什么这一段这样安排**；
- 希望看到一个**从空白到可运行结果的完整示范**，而不是只看到若干局部能力；
- 面对 AI 的大量可能性时，新手容易失去起点，希望**先跟做，再自由发散**；
- 参与者不仅关心屏幕视觉，还关心**表演者、灯光、音乐、屏幕、实体装置如何形成一个完整演出**；
- 实体装置 / 空间创作者需要更明确的入口，不能默认所有人都从“屏幕内容”出发。

## 2. 教学判断

问题不是内容不足，而是当前内容密度高于“第一条可执行路径”的清晰度。

后续补充不应简单继续增加工具数量，而应该强化：

```text
WHY
为什么这一段需要发生？
↓
WHAT
人 / 光 / 声音 / 屏幕 / 空间分别做什么？
↓
HOW
怎样把关系做成一个可以观看和修改的预演？
↓
TOOL
最后才决定用 Web / Three.js / Blender / Arena / AI Agent 等什么工具。
```

## 3. 后续内容优先级

### P0｜一条完整可跟做的流程

从一个短 Opening 或 20–30 秒演出片段开始，完整展示：

```text
参考 / 场地
→ Stage Plot / 空间关系
→ Storyboard / 时间结构
→ Gray Box
→ 屏幕与内容
→ 灯光与音乐
→ Cue / 控制
→ 浏览器预演
→ 看出问题
→ 改第二版
```

目标不是统一大家的风格，而是先让参与者知道一个演出草稿到底怎样从 0 到 1 成立。

### P0｜补齐“屏幕之外”的演出关系

后续示范至少覆盖：

- Performer / 人物位置与移动；
- Lighting / 灯光方向、强弱与状态变化；
- Music / 时间、段落与触发；
- Screen / 屏幕内容与多屏关系；
- Installation / 实体装置或空间物件；
- Cue / 谁在什么时间做什么。

这里采用“用舞台导演的视角检查作品”的表述，不把 AI 或短期学习包装成专业舞台导演资格。

### P1｜继续复用已有视觉与实时控制练习

不重复写一套新的视觉教程，优先连接：

- SceneForge `public/stage-replica/` 下已有 Festival / Stadium / Installation / Sphere / Replay 等案例；
- portfolio 中 2026-08-29 参与者课后延伸：一个按钮、节拍、State、视觉变体与发布流程；
- 现有 Scene Forge 场地查看、映射、实时 source 与 WebXR 路线。

### P1｜把公开页变成持续更新入口

已新增 `web/after-workshop.html`，用于：

- 发布匿名回访结论；
- 说明后续补充方向；
- 提供已有延伸阅读；
- 明确已付费参与者权益；
- 预告后续公开活动。

## 4. 参与者权益说明

公开表达必须保持准确：

> 已付费参加 2026-10-31 工作坊的参与者，将免费获得**本次工作坊后续新增的课程更新与内容补充**，无需重复购买。

这里的“免费”只指本次工作坊的后续内容更新，不自动代表未来线下活动、演出、场地活动或其他课程均免费。

## 5. The Point 后续活动方向

计划继续探索公开的限时创作与演出活动，把以下部分放回真实空间：

- 场景预演；
- 实时视觉；
- 音乐 / DJ；
- 灯光与空间；
- 短时间协作与现场测试。

可能邀请 DJ 与其他创作者参与，但在阵容、时间、形式未确认前，不在公开页面做确定性承诺。

## 6. 对 portfolio 的公开口径

可以公开：

- Scene Forge / 场景铸造作为网页端舞台 / 空间预演工具与长期研究；
- 10/31 工作坊采用“场地 / 参考 → 灰盒 → 内容 → 多媒介关系 → 浏览器预演 → 修改”的方法；
- 匿名聚合后的教学反馈与方法修正；
- 12+ 参与者、8 位希望预演自己的作品、2 个可操作原型等聚合信息（仅在来源和统计口径确认时使用）；
- 后续继续补齐完整示范、Stage Plot / Storyboard / Cue Sheet 与跨媒介协作。

不公开：

- 参与者姓名与账号；
- 私聊截图；
- 可识别的原话与私人经历；
- 未确认的活动阵容、日期、合作关系；
- 任何把“可能 / 计划”写成“已经确定”的宣传表述。

## 7. 当前结论

Scene Forge / 场景铸造不需要因为一次工作坊反馈另起一个版本名或新的产品名。

这轮反馈更适合被理解为：**继续把已有公开库、案例、教学页和真实演出实践连接得更完整。**
