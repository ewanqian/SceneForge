# 舞台复刻 · 课程内容

## 交流创作方向｜13:30—14:00

从一段音乐、一组影像，或一个舞台构想开始。

简短介绍各自的创作方向与想尝试的内容。结合 ENTROPY 的主屏与顶屏、TIMER 的环幕，观察画面进入空间后的变化，了解从 Blender 预演到 AI 辅助网页原型的不同做法。

案例与演示：结合项目图片，介绍屏幕关系、制作中的尝试，以及最后的选择。参考现有演出，也可以搭建尚未实现的舞台构想。

交流问题：今天想尝试什么？有哪些已有的素材或参考？

本段完成：选一个适合三小时内尝试的方向。没有素材或编程基础，可以从统一工程开始。

## 搭建第一个灰盒｜14:00—14:40

用屏幕、人物和观看位置，建立基本空间关系。

在 DeepSeek Harness 中打开工程目录，新建会话，提供参考、尺寸、修改范围和检查方式。先用当前可用的 Flash 完成一项小改动，再打开网页查看结果。遇到问题，补充画面或报错、缩小任务，必要时再尝试 Pro。

案例与演示：委托示例：请先阅读工程，保持屏幕结构与位置，将指定视频放到主屏。沿用现有依赖，并说明运行方法和比例、裁切的检查方式。

交流问题：这次需要改什么？哪些保持原样？怎样检查结果？

本段完成：完成打开工程、委托修改、预览结果的第一轮操作。保留可继续编辑的工程。

## 将画面映射到屏幕｜14:40—15:30 · 含5分钟休息

固定屏幕结构，尝试不同的内容分配。

将视频或实时窗口作为动态纹理，通过 UV 对应到屏幕表面。比较正面与地面、主屏与顶屏、六边形六屏和曲面的画面关系。再打开 Blender，查看屏幕形状与 UV 展开，选择一种结构完成第一版。

案例与演示：TIMER 案例：比较全宽画布与 1:1 圆形内容重新映射的两种尝试。根据内容与观看方式选择，不将单个项目的做法作为通用标准。

交流问题：画面需要跨屏连续，还是在每块屏幕上重复？经过折角时，方向怎样衔接？

本段完成：区分空间预演、内容映射和输出校准；区分曲面、超宽画布与360全景媒体。为第一版安排基本播放顺序。

## 从观众位置观看｜15:30—15:50

完整播放一次，比较不同位置的观看效果。

切换中心、侧面与总览，检查遮挡、画面衔接、人物尺度和音乐变化。先看完整段内容，再记录需要调整的位置与时刻。可以独立观察，也可以邀请同伴一起看。

案例与演示：比较原本希望传达的内容与实际观看的感受。除了比例和裁切，也关注注意力、节奏与情绪。

交流问题：哪些画面被看见了？哪些变化没有传达出来？

本段完成：选出一个值得在第二版中解决的问题，并指出具体机位或时间点。

## 调整并比较第二版｜15:50—16:20

保留第一版，在相同条件下查看变化。

围绕刚才的观察，调整内容分配、播放时刻或映射方向。向 Agent 说明现象与修改范围，查看实际结果。再从相同位置播放相同片段，比较两个版本，保存工程与素材。

案例与演示：委托示例：V1 的这个时间点，从侧面看，关键画面被截断。保持屏幕尺寸和位置，只调整内容分配。保留原版，并说明比较方法。

交流问题：哪一项调整最接近原本的构想？

本段完成：两个版本均可打开。能够说明改了什么，以及变化是否有效。

## 分享发现，继续创作｜16:20—16:30

展示一次修改，确定接下来想尝试的方向。

每人用30秒展示构想、第一版的发现与修改结果。尚未完成的部分，也可以交流具体问题。介绍 SceneForge 舞台库共建计划：为不同屏幕组合命名，整理真实项目的尺寸、拼接关系和观看位置，保留可供后续创作参考的场景。

案例与演示：后续计划包括屏幕规格共享、项目展示页与提交入口。目前尚未开放在线上传，感兴趣的参与者可在课后交流资料与使用范围。

交流问题：下一步准备继续尝试什么？有哪些屏幕结构值得一起保存？

本段完成：保存工程、原素材与版本记录。课后可沿用课程地址查看资料，继续发展作品。
