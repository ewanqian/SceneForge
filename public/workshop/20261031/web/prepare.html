02 / 需要改源码时

安装桌面应用，打开工程

  1. 打开官方桌面下载页，选择系统支持的 DeepSeek Harness 安装包。无需克隆 Harness 仓库或安装 Docker。
  2. 按课堂引导配置 DeepSeek API。浏览器体验不消耗API；让Agent修改工程时才需要配置。建议预留约10—20元，实际费用随调用量变化。
  3. 下载舞台草稿工程，解压后在 Harness 中打开这个文件夹。

Mac与Windows都可先用浏览器参加。若系统没有可用的桌面安装包，先继续网页体验，不在课堂上编译应用。

发送一条小委托

本地预览交给Agent启动，不必先手动配置终端环境。

请先读 AGENTS.md、README.md 和 scene.js，不读取 vendor 中的引擎源码。先使用应用自带或电脑现有的 Node 运行 preview.mjs，打开本地预览；也可使用现有 Python 运行 serve.py。不安装 Docker，不新增框架，不运行 npm install。保留原版，只调整主屏宽度和一个侧面机位。完成后说明怎样比较人物、屏幕和画面的比例。若现有运行时不可用，给出具体情况，先用公开网页继续体验。
