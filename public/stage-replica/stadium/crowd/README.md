# Stadium / 360° — 观众席与视线（人群层）

**在线:** https://ewanqian.github.io/SceneForge/stage-replica/stadium/crowd/
**性质:** Stadium Demo 的人群层。它不是第五种舞台，而是把"95,000 人环绕"从一句话变成**可测量**的东西。

> ⚠️ **PROXY。** ⌀30m 圆形舞台与 ⌀20×8m 圆柱 LED 来自 STUFISH 官方逐字；**观众席的行距、升阶、座位间距、碗体全部是教学 proxy**（参考未公布任何观众席尺寸）。

---

## 1｜三个可测量的东西

| 指标 | 怎么算 | 界面读数 |
|---|---|---|
| **人数 / 密度** | 逐排按弧长与座位间距铺位，扣掉横向通道（每 8 排）与纵向通道（每 28 座），再按目标密度确定性抽稀 | `PEOPLE n / 容量 m`、`DENSITY n 人/m²` |
| **逐排视线 C 值** | 从第 i 排眼位看向焦点，量它越过第 i−1 排**头顶**的垂直余量 | 底部逐排柱状图 + `C MIN` + `FIRST FAIL` |
| **被包围感** | 从艺人位置（舞台中心、眼高 1.6m）量：观众在水平 360° 中占多少，以及人群在垂直方向从几度到几度、最近的人多远 | `ENCIRCLE 水平 x% · 垂直 a°→b° · 最近 d m` |

C 值的定义是这一层里**唯一有行业依据**的部分：剧场常用 60–75mm。**本项目取 60mm 作为判据，这是选择，不是引用规范**——角标和这里都如实标注。

---

## 2｜这一层真正的发现：等升阶在后排会失效

这是整个页面存在的理由。**用固定的升阶高度（0.45m）铺 52 排看台，C 值会随距离衰减，到第 13 排就跌破判据，最后排是负值**——意思是后排观众的视线被前排头部完全挡住。

而这个结论**看渲染图是看不出来的**。画面上只是一片整齐的观众席。

所以页面同时**解算**出能保持目标的升阶剖面：

$$h_i = \frac{C - f + y_{i-1} + P - k\,(y_{i-1} + E - f)}{k},\qquad k = \frac{D_{i-1}}{D_i}$$

| 升阶模式 | 最小 C 值 | 首个不合格排 |
|---|---|---|
| **等升阶 0.45m** | **−59.1 mm**（视线被挡） | **第 13 排**（C=57.8mm） |
| **按 C 值解算** | **60.0 mm** | 无 |

真实场馆之所以把看台做成**上陡下缓的曲线**，原因就在这张表里。按一下 `按 C 值解算升阶` 就能看到整条曲线被拉平。

## 3｜被包围感（实测）

从舞台中心、眼高 1.6m：

| 量 | 值 |
|---|---|
| 水平覆盖 | **100%** 的 360°（每 1° 都有人） |
| 垂直占据 | **2.4° → 19.0°**（在视平线上方） |
| 最近观众 | **18.4 m** |

垂直 19° 这个数字比"95,000 人"更能说明"被包围"是什么感觉：人墙从视平线附近一路升到接近 20°，也就是**要抬头才看得到最上面一排**。

**⚠️ 一个我在构建中发现并修掉的错误：** 第一版把看台内缘放在半径 **32m**，于是艺人站在一条 32m 宽的"护城河"中间，`STAGE_CENTER` 视角里**根本看不到人**，"被包围"在读数是 99.7% 的情况下**画面上是零**。看台已改为从半径 **18m** 起（紧贴 ⌀30m 舞台之外）——这正是 360° in-the-round 的关键。

## 4｜仍未做到 / 已知限制（不掩饰）

1. **容量 26,177 座，不是 95,000。** 参考的 95,000 包含**场地内站立的人群**与 OAKA 既有的、比本 proxy 大得多的看台。本模型**只建了一个代理碗体**，没有建场地站立区。所以这个页面的正确说法是"**一个 2.6 万座碗体的密度与视线研究**"，不是"复现了 9.5 万人"。
2. **场地站立区没有建。** 那部分恰恰有个很值得讲的结论（平地上的人群会自己挡住自己，前排以外基本看不见），但目前只写了这句话，**没有做**。
3. **C 值只算垂直视线**，没有算水平视线（侧向遮挡）、没有算视线到屏幕中心还是舞台边缘的差别、也没有算站立人群的动态遮挡。
4. **观众不做个体行为**：没有走动、没有举手机、没有波浪、没有离场。只有一层很轻的原地摆动（顶点着色器），用来让画面不是一张静止的点阵。
5. **60mm 是选择。** 体育场通常取更大值；改成 75mm 或 90mm 曲线会整体上移。
6. **人体参数是常量**：站姿眼高 1.62m / 头高 1.78m，坐姿 1.20m / 1.34m。没有身高分布，因此 C 值是**对"同一身高"的观众**成立的——真实场馆要按人群的身高分位数算。
7. 没有做疏散/通行能力、没有做轮椅席视线、没有做声压。

## 5｜复现

```bash
npm run build
python -m http.server 8123 --bind 127.0.0.1 -d dist
```

```
?view=BOWL_WIDE|STAGE_CENTER|ROW_20|TOP
?overlay=look|density|sightline|encircle
?density=sparse|normal|packed      0.6 / 1.6 / 2.5 人每平米
?posture=standing|seated
?rake=constant|sightline           等升阶 / 按 C 值解算
?cap=<n>                           限制实例数（无头抓图用；容量仍报真实值）
?probe=1                           把指标写进 DOM，供无头验证
```

无头验证：

```bash
chrome --headless=new --disable-gpu --virtual-time-budget=25000 --dump-dom \
  "http://127.0.0.1:8123/stage-replica/stadium/crowd/?probe=1&rake=sightline" | grep -o '<div id="probe"[^>]*>[^<]*'
```

## 6｜这个页面试图说明的一件事

**"很多人"不是一个人数，是一组几何关系。** 9.5 万人这个数字本身不说明任何体验；说明体验的是：最近的人离你 18m、人墙从视平线升到 19°、以及后排那 40 排人里有多少人其实**看不到你**。

第三件事只有算才知道。
